# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities through public issues, discussions, logs, or chat rooms.

Use GitHub private vulnerability reporting for this repository. Include affected versions, impact, reproduction steps, and any suggested mitigation. Remove real customer data, tokens, payment payloads, and VPN access links from reports.

Maintainers will acknowledge complete reports as soon as practical, validate impact, coordinate a fix, and publish an advisory when users can take action.

## Supported versions

Security fixes are provided for the latest stable release. Operators should run the newest patch release and keep Remnawave, PostgreSQL, Valkey, and the reverse proxy supported and patched.
