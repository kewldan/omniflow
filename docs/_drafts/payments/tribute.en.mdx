## Tribute

Tribute is a Telegram donation service. It has no API for opening a checkout: the customer pays
through your fixed Tribute donation link and chooses the amount there, and Tribute notifies Omniflow
of each donation.

**Currencies:** `RUB` only. Donation amounts are reported in kopeks.

<Warning>
  A Tribute donation names the payer's Telegram account and the donation link, never an Omniflow
  order. Omniflow verifies and records each donation, but cannot match it to an order, so a Tribute
  payment does **not** settle an order on its own. Every verified donation is kept in `/admin` →
  System → Webhooks with the error `payment_not_found` for an operator to resolve.
</Warning>

### Configuration

| Variable | Required | Default | Meaning |
| --- | --- | --- | --- |
| `APP_TRIBUTE_API_KEY` | Yes | — | Tribute API key. It verifies the `trbt-signature` of every webhook. Keep it secret. |
| `APP_TRIBUTE_DONATE_LINK` | Yes | — | Your Tribute donation link. The customer is sent to it as is. |

Setting only one of the two is a startup error; setting neither leaves Tribute disabled.

### Webhook

Enter this address as the webhook URL in Tribute's settings:

```text
https://<APP_PUBLIC_URL>/v1/payments/webhooks/tribute
```

A webhook is accepted only when `trbt-signature` equals `hex(HMAC-SHA256(API key, body))`. A changed
body or a wrong signature is rejected. `new_donation` and `recurrent_donation` are payments;
`cancelled_subscription` and other events change nothing. Redeliveries of one donation share one
event ID, built from the donation link ID, the Telegram user, the amount and the event's
`created_at`.

### Capabilities

| Capability | Supported |
| --- | --- |
| Webhooks | Yes, signed |
| Status polling | No |
| Read-only connection probe | No |
| Refunds | No |
| Recurring charges | No |
| Cancelling an open payment | No |

### Testing

1. Set both variables and restart the API.
2. Make a small donation through the link. The notification appears in `/admin` → System → Webhooks
   with a valid signature.
