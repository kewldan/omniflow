## KassaAI

KassaAI — продукт для мерчантов, работающий на том же API заказов, что и FreeKassa
(`https://api.fk.life/v1`), со своим магазином и своими реквизитами. Адаптер `kassa_ai` работает
параллельно с `freekassa` и никогда не открывает форму выбора: каждая оплата — это заказ через API на
один способ оплаты, по умолчанию СБП.

**Валюта.** Одна валюта на магазин — `RUB`, если `APP_KASSA_AI_CURRENCY` не задаёт другую.

<Steps>
  <Step title="Получите реквизиты магазина">
    Понадобятся идентификатор магазина KassaAI, его API-ключ и секретное слово 2, которым
    подписываются уведомления.
  </Step>
  <Step title="Настройте Omniflow">
    ```env
    APP_KASSA_AI_SHOP_ID=12345
    APP_KASSA_AI_API_KEY=…
    APP_KASSA_AI_SECRET_WORD_2=…
    APP_KASSA_AI_SERVER_IP=203.0.113.10
    APP_PUBLIC_URL=https://shop.example.com
    ```
    Адаптер регистрируется, если задано хотя бы одно из четырёх обязательных значений, а если заданы
    не все, запуск завершается ошибкой с перечнем недостающих.
  </Step>
  <Step title="Укажите URL уведомлений">
    Когда задан `APP_PUBLIC_URL`, каждый заказ передаёт
    `https://<your-public-host>/v1/payments/webhooks/kassa_ai` как URL уведомлений. Без него укажите
    этот URL в личном кабинете.
  </Step>
  <Step title="Оплатите тестовый заказ">
    Купите самый дешёвый тариф сами и проверьте его по разделу **Как убедиться, что провайдер
    действительно работает** на странице платёжных провайдеров.
  </Step>
</Steps>

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `APP_KASSA_AI_SHOP_ID` | Да | — | Числовой идентификатор магазина |
| `APP_KASSA_AI_API_KEY` | Да | — | API-ключ. Ключ HMAC-SHA256 для заказов, опроса статуса и проверки баланса |
| `APP_KASSA_AI_SECRET_WORD_2` | Да | — | Проверяет уведомления |
| `APP_KASSA_AI_SERVER_IP` | Да | — | Публичный IPv4-адрес сервера Omniflow, передаётся в обязательном поле заказа `ip` |
| `APP_KASSA_AI_PAYMENT_SYSTEM_ID` | Нет | `44` | Способ оплаты: `sbp` (44, СБП по QR-коду), `card` (36, российские карты), `sberpay` (43, SberPay) или числовой идентификатор платёжной системы |
| `APP_KASSA_AI_CURRENCY` | Нет | `RUB` | Единственная валюта, в которой работает магазин |

**Создание.** JSON-запрос `POST /orders/create` с полями `shopId`, `nonce`, `paymentId`
(идентификатор заказа Omniflow), `i`, `email`, `ip`, `amount`, `currency`, `success_url` и `fail_url`
(оба — возвратный URL заказа) и `notification_url`, когда задан `APP_PUBLIC_URL`. Он подписывается
HMAC-SHA256 с API-ключом от значений, отсортированных по ключу и соединённых через `|`. Omniflow не
передаёт KassaAI адрес клиента; обязательное поле `email` отправляется как
`user_<идентификатор заказа>@telegram.org`. Клиент переходит по ссылке `location`, которую возвращает
API.

**Проверка вебхука.** Так же, как у FreeKassa: форма с полями `MERCHANT_ID`, `AMOUNT`,
`MERCHANT_ORDER_ID`, `intid` и `SIGN = md5(MERCHANT_ID:AMOUNT:секретное слово 2:MERCHANT_ORDER_ID)`,
проверяемая за постоянное время, с ответом голым телом `YES`. Идентификатор события — `paid:<intid>`.

**Опрос статуса.** Поддерживается через `POST /orders`; статус `1` — оплачен, любой другой остаётся в
ожидании.

**Возвраты и рекуррентные платежи.** Не поддерживаются.
