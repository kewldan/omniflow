## Tribute

Tribute — сервис донатов в Telegram. API для открытия оплаты у него нет: покупатель платит по вашей
постоянной донат-ссылке Tribute и сам выбирает там сумму, а Tribute уведомляет Omniflow о каждом
донате.

**Валюты:** только `RUB`. Суммы донатов приходят в копейках.

<Warning>
  Донат Tribute называет Telegram-аккаунт плательщика и донат-ссылку, но никогда — заказ Omniflow.
  Omniflow проверяет и записывает каждый донат, но не может сопоставить его с заказом, поэтому платёж
  через Tribute **сам по себе не оплачивает** заказ. Каждый проверенный донат остаётся в `/admin` →
  System → Webhooks с ошибкой `payment_not_found`, и разбирает его оператор.
</Warning>

### Настройка

| Переменная | Обязательна | По умолчанию | Значение |
| --- | --- | --- | --- |
| `APP_TRIBUTE_API_KEY` | Да | — | API-ключ Tribute. Им проверяется `trbt-signature` каждого вебхука. Держите в секрете. |
| `APP_TRIBUTE_DONATE_LINK` | Да | — | Ваша донат-ссылка Tribute. Покупатель переходит по ней без изменений. |

Если задана только одна из двух переменных, запуск завершается ошибкой; если не задана ни одна,
Tribute выключен.

### Вебхук

Укажите этот адрес как URL вебхука в настройках Tribute:

```text
https://<APP_PUBLIC_URL>/v1/payments/webhooks/tribute
```

Вебхук принимается, только если `trbt-signature` равен `hex(HMAC-SHA256(API-ключ, тело))`. Изменённое
тело или неверная подпись отклоняются. `new_donation` и `recurrent_donation` — это платежи;
`cancelled_subscription` и другие события ничего не меняют. Повторные доставки одного доната имеют
один ID события, собранный из ID донат-ссылки, Telegram-пользователя, суммы и `created_at` события.

### Возможности

| Возможность | Поддерживается |
| --- | --- |
| Вебхуки | Да, с подписью |
| Опрос статуса | Нет |
| Проверка подключения только на чтение | Нет |
| Возвраты | Нет |
| Рекуррентные списания | Нет |
| Отмена открытого платежа | Нет |

### Проверка

1. Задайте обе переменные и перезапустите API.
2. Сделайте небольшой донат по ссылке. Уведомление появится в `/admin` → System → Webhooks с верной
   подписью.
