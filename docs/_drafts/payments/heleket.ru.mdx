## Heleket

Heleket — криптовалютный платёжный шлюз. Omniflow выставляет в Heleket счёт в фиатной валюте заказа;
покупатель оплачивает его криптовалютой на странице Heleket, а Heleket сообщает результат на вебхук
Omniflow.

**Валюты:** заказы в `RUB` или `USD`. Монету, которой платит покупатель, задаёт
`APP_HELEKET_DEFAULT_CURRENCY`.

### Настройка

| Переменная | Обязательна | По умолчанию | Значение |
| --- | --- | --- | --- |
| `APP_HELEKET_MERCHANT_ID` | Да | — | UUID мерчанта из кабинета Heleket, передаётся в заголовке `merchant`. |
| `APP_HELEKET_API_KEY` | Да | — | Платёжный API-ключ. Им подписывается каждый запрос и проверяется каждый вебхук. Держите в секрете. |
| `APP_HELEKET_BASE_URL` | Нет | `https://api.heleket.com/v1` | Базовый адрес API. |
| `APP_HELEKET_DEFAULT_CURRENCY` | Нет | `USDT` | Монета, в которую конвертируется счёт (`to_currency`). |
| `APP_HELEKET_DEFAULT_NETWORK` | Нет | — | Сеть блокчейна для этой монеты (`network`), например `tron`. Если не задана, сеть выбирает покупатель. |
| `APP_HELEKET_INVOICE_LIFETIME` | Нет | `3600` | Время жизни счёта в секундах, в пределах от 300 до 43200. |
| `APP_HELEKET_MARKUP_PERCENT` | Нет | `0` | Наценка для покупателя в процентах. Округляется до целого и передаётся как отрицательный `discount_percent`. |

Также обязателен `APP_PUBLIC_URL`: каждый счёт несёт адрес вебхука в `url_callback`, поэтому без него
Omniflow не запускает адаптер. Если задан только один из двух ключей, запуск завершается ошибкой; если
не задан ни один, Heleket выключен.

### Вебхук

Адрес обратного вызова уже передаётся в каждом счёте, поэтому в кабинете ничего вводить не нужно. Он
такой:

```text
https://<APP_PUBLIC_URL>/v1/payments/webhooks/heleket
```

Уведомление принимается, только если его поле `sign` совпадает с `md5(base64(тело) + API-ключ)`,
посчитанным по телу без `sign`. Уведомление без подписи, с неверной подписью или с изменённой суммой
отклоняется. Заказ оплачивают только статусы `paid` и `paid_over`; любой другой статус записывается и
ничего не меняет.

### Возможности

| Возможность | Поддерживается |
| --- | --- |
| Вебхуки | Да, с подписью |
| Опрос статуса | Да, через `payment/info` |
| Проверка подключения только на чтение | Да, `payment/list` |
| Возвраты | Нет |
| Рекуррентные списания | Нет |
| Отмена открытого счёта | Нет |

### Проверка

1. Задайте переменные выше и `APP_PUBLIC_URL` и перезапустите API. Ошибка запуска называет
   отсутствующую или заданную наполовину переменную.
2. При желании вызовите `POST /v1/panel/settings/providers/heleket/test`. Он выполняет проверку только
   на чтение; где сейчас виден её результат, описано в разделе «Как убедиться, что провайдер
   действительно работает» на странице [Платежи](/ru/integrations/payments).
3. Купите самую дешёвую версию тарифа сами через Heleket. Следите за уведомлением в `/admin` → System →
   Webhooks и за историей платежа в `/admin/finance/{orderId}`. Если вебхук не пришёл, сверка прочитает
   статус счёта через `payment/info`.
