## WATA

WATA (`https://api.wata.pro/api/h2h`) выдаёт ссылки на оплату. Адаптер `wata` создаёт ссылку для
каждого заказа, отправляет по ней клиента и зачисляет платёж по уведомлению о транзакции, подписанному
RSA.

**Валюта.** Только `RUB`.

<Steps>
  <Step title="Получите реквизиты">
    Понадобится токен доступа WATA для вашего терминала.
  </Step>
  <Step title="Настройте Omniflow">
    ```env
    APP_WATA_ACCESS_TOKEN=…
    ```
    Адаптер регистрируется, когда задан `APP_WATA_ACCESS_TOKEN`.
  </Step>
  <Step title="Укажите URL уведомлений">
    В аккаунте WATA направьте уведомления на
    `https://<your-public-host>/v1/payments/webhooks/wata`.
  </Step>
  <Step title="Оплатите тестовый заказ">
    Купите самый дешёвый тариф сами и проверьте его по разделу **Как убедиться, что провайдер
    действительно работает** на странице платёжных провайдеров. Проверка подключения запрашивает
    одну транзакцию из списка, поэтому подтверждает токен, ничего не создавая.
  </Step>
</Steps>

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `APP_WATA_ACCESS_TOKEN` | Да | — | Bearer-токен для каждого вызова API |
| `APP_WATA_BASE_URL` | Нет | `https://api.wata.pro/api/h2h` | Базовый URL API |
| `APP_WATA_PAYMENT_TYPE` | Нет | `OneTime` | Передаётся как `type` ссылки |
| `APP_WATA_PAYMENT_DESCRIPTION` | Нет | — | Описание ссылки, если у заказа нет собственного |
| `APP_WATA_SUCCESS_REDIRECT_URL` | Нет | — | Страница успеха; используется, только если у заказа нет собственного возвратного URL |
| `APP_WATA_FAIL_REDIRECT_URL` | Нет | возвратный URL заказа | Страница ошибки |
| `APP_WATA_LINK_TTL_MINUTES` | Нет | не задано | Время жизни ссылки в минутах. Без значения срок не передаётся; значения меньше 15 поднимаются до 15, потому что WATA отклоняет срок истечения в пределах десяти минут |
| `APP_WATA_REQUEST_TIMEOUT` | Нет | `30` | Таймаут API в секундах |
| `APP_WATA_PUBLIC_KEY_URL` | Нет | `<базовый URL>/public-key` | Откуда загружается публичный ключ для проверки уведомлений |
| `APP_WATA_PUBLIC_KEY_CACHE_SECONDS` | Нет | `3600` | Сколько кешируется публичный ключ; `0` — до перезапуска |

**Создание.** `POST /links` с полями `amount`, `currency`, `description`, `orderId` (идентификатор
заказа Omniflow), `type`, `successRedirectUrl`, `failRedirectUrl` и `expirationDateTime`, если задан
срок жизни. Идентификатор ссылки `id` становится ссылкой провайдера.

**Проверка вебхука.** WATA подписывает сырое тело RSA (PKCS#1 v1.5, SHA-512) и передаёт подпись в
base64 в заголовке `X-Signature`. Omniflow проверяет её публичным ключом, который публикует WATA:
ключ загружается при первом использовании и кешируется; если обновление не удалось, продолжает
использоваться уже полученный ключ. Если ключа нет вовсе, проверить ничего нельзя, и уведомление
отклоняется, чтобы WATA повторила доставку. `transactionStatus` `Paid` зачисляет подписанную сумму
`amount`, `Declined` → failed, остальное → pending. Идентификатор события —
`<transactionStatus>:<transactionId>`. На проверенное уведомление отвечается `{"status":"ok"}`.

**Опрос статуса.** Поддерживается. `GET /links/{id}`; когда ссылка закрыта или оплачена —
`GET /transactions` с фильтром по этой ссылке и заказу и статусом `Paid`. Зачисляет платёж только
оплаченная транзакция — на её сумму.

**Возвраты и рекуррентные платежи.** Не поддерживаются.
