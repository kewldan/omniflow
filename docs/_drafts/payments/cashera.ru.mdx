## Cashera

Cashera (`api.cashera.cash`) — платёжный шлюз с интеграцией сервер-сервер, принимающий рубли через СБП,
картой и другими способами. Omniflow создаёт транзакцию Cashera и отправляет покупателя на страницу
оплаты Cashera.

**Валюты:** только `RUB`. Суммы передаются целым числом копеек.

### Настройка

| Переменная | Обязательна | По умолчанию | Значение |
| --- | --- | --- | --- |
| `APP_CASHERA_API_KEY` | Да | — | Публичный ключ (`pk_…`) из раздела **Настройки** Cashera, передаётся как `X-Api-Key`. |
| `APP_CASHERA_API_SECRET` | Да | — | Секрет (`sk_…`). Cashera присылает его в `X-Secret` в каждом вебхуке; Omniflow его никогда не отправляет. Держите в секрете. |
| `APP_CASHERA_PAYMENT_METHOD` | Нет | — | `sbp`, `card`, `mastercard`, `crypto` или `cryptobot`. Если не задан, открывается общая форма Cashera, где способ выбирает покупатель. Метод должен быть включён в «Методах приёма» кабинета, иначе Cashera отвечает `422`. |
| `APP_CASHERA_BASE_URL` | Нет | `https://api.cashera.cash/api/v1` | Базовый адрес API. |
| `APP_CASHERA_RETURN_URL` | Нет | — | Страница успеха, если оформление заказа её не передало. |
| `APP_CASHERA_FAILED_URL` | Нет | страница успеха | Страница для неудачной оплаты. |

Если задан только один из двух ключей, запуск завершается ошибкой; если не задан ни один, Cashera
выключена.

### Вебхук

```text
https://<APP_PUBLIC_URL>/v1/payments/webhooks/cashera
```

Если задан `APP_PUBLIC_URL`, Omniflow передаёт этот адрес как `callback_url` в каждой транзакции. Без
него адрес колбэка не передаётся, и Cashera берёт адрес, сохранённый в кабинете мерчанта, — укажите его
там. Cashera требует HTTPS на публичном хосте.

Вебхук принимается, только если его заголовки `X-Api-Key` и `X-Secret` совпадают с вашими ключом и
секретом. Заказ оплачивает только `transaction.status_updated` со статусом `paid`. Остальные события,
например `webhook.test` из кабинета, получают ответ `200` и ничего не меняют. Событие `paid` без суммы
отклоняется.

### Возможности

| Возможность | Поддерживается |
| --- | --- |
| Вебхуки | Да, с аутентификацией по заголовкам |
| Опрос статуса | Да, `GET /integration/transactions/{uuid}` |
| Идемпотентное создание | Да, ID заказа — это `external_id` Cashera |
| Проверка подключения только на чтение | Нет |
| Возвраты | Нет |
| Рекуррентные списания | Нет. Подписки Cashera (`sbp_recurring`) не используются |
| Отмена открытой транзакции | Нет |

### Проверка

1. Задайте переменные выше и перезапустите API. Ошибка запуска называет отсутствующую или неверную
   переменную.
2. Отправьте тестовый вебхук из кабинета Cashera. Он появится в `/admin` → System → Webhooks и получит
   ответ `200`.
3. Купите самую дешёвую версию тарифа сами через Cashera и следите за историей платежа в
   `/admin/finance/{orderId}`. Если вебхук не пришёл, сверка прочитает статус транзакции.
