## CisPay

CisPay — размещённая платёжная страница поверх Merchant API CisPay (`https://api.cispay.app`).
Omniflow создаёт платёж, отправляет покупателя на страницу оплаты CisPay и закрывает заказ, когда
CisPay сообщает об оплате. Суммы передаются целыми копейками.

**Валюты:** только `RUB`.

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `APP_CISPAY_SHOP_ID` | Да | — | UUID магазина, передаётся в `X-Shop-ID`. |
| `APP_CISPAY_API_KEY` | Да | — | Секретный ключ (`cis_sec_…`), передаётся в `X-Api-Key` и проверяет подпись webhook. |
| `APP_CISPAY_PAYMENT_METHOD` | Нет | пусто | `CARD`, `SBP` или `CRYPTO`. Пустое значение оставляет выбор покупателю на странице CisPay. |
| `APP_CISPAY_BASE_URL` | Нет | `https://api.cispay.app` | Адрес API. |

Если задана только одна из двух обязательных переменных, запуск завершается ошибкой. Оплата картой
начинается с 50,00 RUB; меньшая сумма для карты отклоняется до обращения к CisPay.

<Steps>
  <Step title="Настройте Omniflow">
    Задайте `APP_CISPAY_SHOP_ID` и `APP_CISPAY_API_KEY`, затем перезапустите API и worker.
  </Step>
  <Step title="Укажите адрес webhook">
    В кабинете CisPay направьте уведомления на
    `https://<APP_PUBLIC_URL>/v1/payments/webhooks/cispay`.
  </Step>
  <Step title="Проверьте подключение">
    Проверка подключения читает `GET /store/capabilities`. Она не проходит, если ключ принадлежит
    другому магазину или магазин неактивен. Ничего не создаётся.
  </Step>
</Steps>

**Проверка webhook.** `X-Signature` — hex HMAC-SHA256 точного тела запроса с API-ключом; подпись
должна совпасть. Уведомление должно относиться к настроенному магазину. Затем Omniflow перечитывает
платёж через `GET /payments/status` и применяет только этот ответ: уведомление может не содержать
признака песочницы, а криптоплатёж может сообщать сумму в центах USD. Криптоплатёж закрывается по
рублёвой `source_amount`. ID события webhook — `{status}:{paymentID}`, поэтому повторная доставка
распознаётся как дубль.

**Тестовые платежи.** Платёж с `is_sandbox` или с `block_reason` никогда не считается оплаченным и
отражается как неуспешный.

**Подписки.** Уведомления о подписках CisPay (`X-CISPay-Event`, `subscription_id`) отклоняются:
Omniflow не открывает подписки CisPay.

**Возвраты и автосписания.** Не поддерживаются. В Merchant API нет вызова возврата, а подписки
CisPay — это расписание, которое ведёт сам CisPay, а не списание сохранённого способа оплаты.

**Опрос статуса.** Поддерживается через `GET /payments/status`.

**Проверка.** Тестовый магазин CisPay позволяет убедиться, что webhook доходит и проходит проверку
подписи. Тестовый платёж никогда не закрывает заказ, поэтому полная проверка зачисления требует
реального платежа.
