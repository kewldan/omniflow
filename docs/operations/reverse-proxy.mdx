---
title: Reverse proxy
description: Use Caddy, Traefik, Nginx, or another compatible ingress.
---

Omniflow does not require or automatically start a reverse proxy. Operators may choose Caddy, Traefik, Nginx, HAProxy, or a managed ingress.

The proxy must provide TLS, preserve request IDs, enforce body limits, and route API, web, Telegram webhook, and provider webhook traffic correctly. Customer and admin routes are served by the same web container. Configure trusted proxy headers explicitly; never trust arbitrary `X-Forwarded-For` input.

A maintained Caddy example is available at `deploy/proxies/Caddyfile`.

The example uses `WEB_DOMAIN` for the unified customer/admin application and `API_DOMAIN` for the Go API. The admin workspace remains under `/admin` on the web origin.
