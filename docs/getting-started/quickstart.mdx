## Requirements

- Docker with Compose v2
- A reachable Remnawave v3.2.2 installation
- A Telegram bot token for bot flows

## Start the core stack

```bash
cp .env.example .env
docker compose up --build postgres valkey migrate api bot worker
```

The bot remains disabled when `APP_TELEGRAM_TOKEN` is empty. To exercise the Telegram flow, configure the Telegram token, Remnawave URL/token, and an optional support URL before starting the bot service.

The API listens on `http://localhost:8080` by default. Check it with:

```bash
curl http://localhost:8080/healthz
```

## Start web applications

The customer and admin surfaces share one application behind the optional `web` profile:

```bash
docker compose --profile web up --build
```

- Customer account: `http://localhost:3000`
- Admin workspace: `http://localhost:3000/admin`

The panel has no operator account yet. On first start the API writes a one-time
setup token to its log:

```
level=WARN msg="no administrator exists yet; redeem this one-time setup token at /admin/setup" token=... expires_in=30m0s
```

Open `/admin/setup`, paste the token, and create the first owner. The token is
valid for 30 minutes, can be used once, and stops working permanently as soon as
an operator account exists. Then set up two-factor authentication under
**Security** — see [Admin panel](/operations/admin-panel).
