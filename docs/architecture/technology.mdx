| Layer | Technology |
| --- | --- |
| Backend | Go 1.26, Chi, OpenAPI, pgx, sqlc, River |
| Data | PostgreSQL 18, Atlas, Valkey 9 |
| Frontend | One Next.js 16.3 app, React, TypeScript 7, SWR, Zustand, Tailwind v4, shadcn/ui |
| Forms | React Hook Form and Zod |
| Localization | next-intl, Russian and English |
| Tooling | Bun workspaces, Biome formatting and linting, Orval Fetch/SWR generation |
| Observability | slog, OpenTelemetry, Prometheus |
| Deployment | Docker Compose; user-selected reverse proxy |

NATS, WASM plugins, Kubernetes, Helm, Pulumi, and a dependency-injection framework are intentionally deferred until demonstrated scale or extension requirements justify them.
